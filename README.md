# MindMate - Mental Health Journal App

A full-stack mental health journal application with mood tracking, journaling, AI therapist, and analytics.

## Features
- 🎯 Mood Tracking with intensity and factors
- 📝 Journal entries with search and filter
- 🤖 AI Therapist with breathing exercises
- 📊 Analytics with charts and insights
- 🌐 English/Amharic bilingual support
- 📱 Fully responsive design
